## What I'm building

**Agent tooling**

- [CodeGrid](https://github.com/ZipLyne-Agency/CodeGrid): a terminal workspace for AI coding agents. Run dozens of sessions on a 2D canvas. ([codegrid.app](https://codegrid.app))
- [Agent Lanes](https://github.com/ZipLyne-Agency/Agent-Lanes): let many agents use your real, logged-in Chrome at once, in the background.
- [TapLyne](https://github.com/isaachorowitz/TapLyne-App): gives AI agents a real iPhone through USB capture and Bluetooth input.
- [ZipLyne Lens](https://github.com/ZipLyne-Agency/Ziplyne-Lens): local AI coding spend and prompt intelligence.

**Mac apps**

- [keet](https://github.com/ZipLyne-Agency/keet): push-to-talk dictation. Hold Option, talk, let go. Runs on the Neural Engine, nothing leaves your Mac.
- [WitzLyte](https://github.com/ZipLyne-Agency/WitzLyte): menu bar brightness control using your display's XDR headroom.
- [SpaceNamer](https://github.com/ZipLyne-Agency/SpaceNamer): name, save, and restore Spaces across displays.
- [Grove](https://github.com/ZipLyne-Agency/Grove): a native GitHub repository manager with menu bar search.
- [Facet](https://github.com/isaachorowitz/Facet): a private, on-device mirror for your face, posture, hands, and voice.

**On the web**

- [Shelters](https://github.com/isaachorowitz/Shelters): find the nearest bomb shelter in Israel in one tap. Free, open source, works offline. ([getshelter.app](https://getshelter.app))
- [Asteroid Map](https://github.com/ZipLyne-Agency/Asteroid-Map): simulate asteroid impacts anywhere on Earth with real NASA data. ([asteroidmap.com](https://asteroidmap.com))
- [baba HebrewCore](https://github.com/ZipLyne-Agency/Hebrew-Core-by-baba): Hebrew translation, nikud, and transliteration as an API and MCP server.
- [Mentionwell](https://mentionwell.com): blogs written for search and AI answer engines, with starters for [Next.js](https://github.com/ZipLyne-Agency/mentionwell-nextjs-starter) and [Vite](https://github.com/ZipLyne-Agency/mentionwell-vite-react-starter).
